# Aether：交流、创作、再交流

## 产品主线

以 main 中的 2.0 原版交互为准。主页保留原有 /og.jpg 封面和开始对话入口；不在页面展示流程步骤条。

PC 端进入对话后，左侧常驻 Session 列表。交流中自然出现创作邀请，用户也可以主动进入画布；绘画页独立展示大画布与材料实验室，不再被右侧聊天栏挤占。完成创作后回到同一段交流，画作展示在交流左侧，可继续修改或框选局部交流。

新的纸张、色粉、混合媒材视觉融入交流背景；墨迹、色粉、炭笔、色洗、游丝、擦除和笔触设置保留在绘画页。作品与对话的关联、自动保存和个人展览保持。取消轮流接画，AI 作画尚未启用。

## 独立旅程

每段旅程独立拥有标题、对话、作品、活动画作、交流/创作/画后交流/暂停阶段、输入草稿、创作线索、交流偏好、创作邀请和展览选择。切换旅程时停止当前生成，避免跨会话混入回应。

PC 左侧「对话记录」支持新建、搜索、继续、重命名、收藏、归档与恢复。移除采用可恢复的「最近移除」，不直接销毁作品。「先到这里」允许暂停并在之后继续。

## 保存与迁移

代码位于 GitHub 云端，不依赖开发者本机。用户体验数据通过 IndexedDB 自动保存在当前浏览器；保存失败会明确提示导出，不假装已经保存。尚未接入账号和跨设备云同步。

支持单段旅程和全部旅程导出（version 3）；导入会建立独立会话并重映射作品、对话、展览关联，避免混入当前会话。兼容前一预览版的 version 2 和 creative-journey 版的 version 1 旅程。旧图片作为基础图层保留，可继续叠加材料笔触。

浏览器存储按网址隔离。换电脑、清理浏览器或从预览切换到正式网址前，需要导出全部旅程后重新导入。
