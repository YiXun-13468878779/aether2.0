# Aether 艺术工作室升级

## 产品主线

对话 → 自由创作 → 认真观看作品 → 继续交流或创作 → 用户自己的展览。
保留作品分析的深度、整幅画与多个细节的关系、对话上下文、流式回应和自然创作邀请。默认不引用艺术家或著作来收尾；只有用户明确要求相关知识时才引入。

本轮确认的重点：
- 原创混合媒材封面与新的艺术视觉系统。
- 材料实验室：墨迹、色粉、炭笔、色洗、游丝和擦除；笔宽、浓度、颜料、纸色可调。
- 可重放笔触、独立作品、撤销/重做、可撤销清空、复制继续、导入图片、导出 PNG。
- 画面交流：用户框选局部后再主动发送文字；模型同时收到完整作品、准确裁图与已有对话。
- 个人展览：用户选作品、选对话、写标题与介绍；逐幅观看并通过浏览器打印保存 PDF。

明确取消“你一笔、AI 一笔”的视觉接话，不主动要求 AI 回画。AI 作画不是主流程，本轮未接入绘画生成接口；未来只接受用户主动请求，不能挤占已有分析与交流。

## 数据与换电脑

应用代码已经提交云端，不依赖本机目录。体验数据目前只在打开的页面内存中，没有接入云数据库；页面内明确提示离开前导出旅程。
新版 JSON version 2 保存可编辑笔触、作品、对话和展览选择。导入时重映射 ID，保留作品父子关系、对话关联和展览内容，允许与当前旅程并存。
新版导入器仅接受 version 2，不假装兼容旧格式。后续如需迁移旧版导出文件，应单独增加明确的格式转换。

## 验证与已知边界

GitHub Actions 执行 lint、Next.js 构建和 26 项测试，覆盖模型错误、整图上下文、框选裁图、输入体积限制、笔触历史、复制时的状态更新、导入关联、自然语言偏好。
浏览器检查包括 1280px 桌面和 390px 手机布局、实际画笔、撤销/重做、复制、完整作品交流、局部交流、展览选择/翻页及返回主页。
模型的观看仍可能有偏差，用户应能继续指出和修正。裁图帮助界定局部，并不构成理解准确性的保证。
访客额度仍为实例内预览额度，上线扩大访问前需要持久化额度控制。登录、云数据保存与分享链接属于后续工作。
