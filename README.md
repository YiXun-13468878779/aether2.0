# Aether 2.0

> 让作品先出现，让理解慢慢抵达。

Aether 是一个受原生艺术精神启发的自由创作与作品交流空间。用户可以直接在画布上创作或上传已有作品，AI 会认真观看、提出自己的感受并继续自然对话，但不会诊断用户，也不会替用户定义作品。

## 当前 MVP

- 自由画布：画笔、橡皮、颜色、笔触、撤销、重做与清空
- 作品导入：支持 PNG、JPEG 和 WebP，并可继续创作
- 自然交流：自由文本对话，不使用“有共鸣 / 没共鸣”等机器化反馈按钮
- 动态阅画：依据画面颜色、空间分布、重心与留白生成有视觉依据的整体回应
- 多旅程：新建、恢复和管理相互独立的创作 Session
- 绘画空间：作品收藏、下载和删除
- 隐私优先：当前版本默认仅保存在用户设备
- 安全边界：不提供心理诊断；明确危机表达会中断作品分析并优先支持用户安全
- 响应式体验：桌面端并置画布与对话，移动端纵向适配

## 产品原则

1. 用户是创作者，不是被检测的对象。
2. 作品是作品，不是症状或人格证据。
3. AI 的观看可以大胆，但必须具体、有依据且保持可争辩。
4. 不解释、停下或只保存原图，都可以是完整的创作。
5. AI 不代替用户生成作品。

## 本地运行

```bash
npm install
npm run dev
```

打开 `http://localhost:3000`。

## 技术说明

当前版本使用 React、TypeScript、Vinext 与原生 Canvas API。为满足作品集演示的稳定性，阅画功能首先提供无需外部 API Key 的本地 Demo 模式；后续会通过 Provider Adapter 接入多模态模型，并保持相同的对话与安全契约。

## 重要声明

Aether 是自由创作与作品交流工具，不是心理咨询、心理治疗或医疗服务。
